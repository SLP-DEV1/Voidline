# Help Voidline Grow

If Voidline is useful to you:

- Star the repository so others can discover it.
- Use GitHub Issues for reproducible bugs and packaging problems.
- Share the latest GitHub Release rather than re-uploading individual runtime files.
- Link directly to the repository so users can verify checksums and read release notes.

For binary integrity, always use the release ZIP and matching `SHA256SUMS.txt` from this repository.
