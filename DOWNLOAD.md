# Download Voidline

Use the latest GitHub Release for the packaged binary bundle.

- Download the versioned `Voidline-vX.Y.Z.zip` asset.
- Download `SHA256SUMS.txt` from the same release.
- Verify the archive hash before extracting it.
- Extract the entire ZIP; do not copy only `Voidline.exe`.
- Install the .NET 9 Desktop Runtime if required.

For the current release, see: https://github.com/SLP-DEV1/Voidline/releases/latest
