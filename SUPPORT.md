# Support

Before opening an issue:

1. Download the latest packaged GitHub Release.
2. Verify the release archive using `SHA256SUMS.txt`.
3. Extract the complete archive into one folder.
4. Confirm the .NET 9 Desktop Runtime is installed.
5. Reproduce the problem in a local/offline or otherwise authorized environment.

When reporting a problem, include the Voidline release tag, Windows version, .NET runtime version, reproduction steps, and any error text.

Source-code support and build-from-source requests are outside the scope of this binary-only repository.
