# Roadmap

Repository-focused priorities for the binary-only distribution:

1. Keep every public `v*` release available as a versioned ZIP.
2. Publish SHA-256 checksums with each release.
3. Keep release notes concise and compatibility-focused.
4. Align compiled application metadata with release tags.
5. Add a real UI screenshot or short GIF when available.
6. Keep issue templates and support guidance current.
